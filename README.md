# Finanzas & Hábitos — Gestor Personal Full-Stack

Aplicación web ligera para el registro diario de ingresos/gastos y el seguimiento de hábitos y rachas personales. Desarrollada como proyecto práctico para la **Unidad Didáctica 1: Control de Versiones**.

## Arquitectura del Proyecto

```text
finanzas-habitos-app/
├── docs/               # Esquema relacional SQL y notas técnicas
├── backend/            # API REST con Node.js, Express y SQLite
└── frontend/           # Interfaz web en HTML5, Tailwind CSS y JS Vanilla
```
